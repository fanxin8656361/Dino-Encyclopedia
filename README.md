这是一个以“恐龙百科/数字博物馆”为主题的静态前端项目。它不是复杂的全栈应用，而是一个纯前端的网站，核心功能是：

- 展示 68 种恐龙的卡片和详细信息
- 支持按搜索词、地质时期、食性筛选
- 展示恐龙详情弹窗（栖息地、发现历史、特征、趣闻等）
- 3 个主要古生物时代的时间轴
- “随机发现”按钮
- 中文 / English / 日本語 三语言界面
- 暗色自然历史博物馆风格设计
- 无需构建工具，直接用浏览器打开或者用本地服务器预览

从仓库结构看，项目非常轻量：

- `index.html`：页面主体和交互逻辑
- `data/dinosaurs.js`：恐龙数据源
- `data/i18n.js`：多语言文本
- `assets/`：图标等资源
- `images/` 与 `videos/`：图片和背景视频
- `README.md`：项目说明



注意点：

- 这是纯前端静态项目，没有测试框架，主要靠浏览器手动验证
- 如果修改 `data/dinosaurs.js`，要保持结构一致，避免破坏前端读取逻辑
- 新增图片时最好和现有命名风格一致
